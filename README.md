## Description

**Flowbrand Marketing Service** — NestJS API scaffold with **PostgreSQL** and **TypeORM**, structured for a Stage 5–style feature (RFC first, then implementation). Replace the sample `User` module with the domain from your RFC.

### Stack

- NestJS 11, TypeORM, `pg`
- `@nestjs/config` with `.env` / `.env.local`
- Global prefix `api`, `ValidationPipe` (whitelist + transform)
- Optional local DB: `docker compose up -d` (Postgres 16)

### HTTP routes (initial)

| Method | Path | Notes |
|--------|------|--------|
| GET | `/api` | Hello (starter) |
| GET | `/api/health` | Liveness (no DB query) |
| GET | `/api/users` | Lists users (requires DB + schema) |

### OpenAPI (Swagger UI)

With the app running, open **`/api/docs`** for interactive OpenAPI documentation. Set `PUBLIC_URL` in production so “Try it out” targets your deployed host (see `.env.example`). Disable with `SWAGGER_ENABLED=false` if you do not want docs exposed.

### Deploy (Docker)

Build and run (set database env vars to match your Postgres; `PORT` is optional, default `3000`):

```bash
docker build -t flowbrand-marketing-service .
docker run --rm -p 3000:3000 -e DB_HOST=... -e DB_PORT=5432 -e DB_USERNAME=... -e DB_PASSWORD=... -e DB_NAME=... -e TYPEORM_SYNC=false -e PUBLIC_URL=http://localhost:3000 flowbrand-marketing-service
```

Then visit `http://localhost:3000/api/docs`. For managed platforms (Render, Fly.io, Railway, Azure, AWS, [Nest Mau](https://mau.nestjs.com)), use this `Dockerfile` or `npm run build` + `npm run start:prod`, bind `PORT` from the platform, and attach a Postgres instance.

### Environment

Copy `.env.example` to `.env`. For first-time local schema without migrations, set `TYPEORM_SYNC=true` **only in development** — use migrations before production.

End-to-end tests boot the full `AppModule` and **require a running Postgres** that matches your `.env`.

## Project setup

```bash
$ npm install
$ copy .env.example .env   # Windows — adjust credentials if needed
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```

When you're ready to deploy your NestJS application to production, there are some key steps you can take to ensure it runs as efficiently as possible. Check out the [deployment documentation](https://docs.nestjs.com/deployment) for more information.

If you are looking for a cloud-based platform to deploy your NestJS application, check out [Mau](https://mau.nestjs.com), our official platform for deploying NestJS applications on AWS. Mau makes deployment straightforward and fast, requiring just a few simple steps:

```bash

```

With Mau, you can deploy your application in just a few clicks, allowing you to focus on building features rather than managing infrastructure.
